# White Point

![A MacBook showing a book in dark mode, with White Point off on the left half of the screen and on for the right half](docs/images/hero.png)

A lightweight macOS menu bar utility that dims whites in your main display evenly, inspired by the 'Reduce White Point' setting on iPhone and iPad.

Even with the brightness turned down, white backgrounds and bright text can still feel like they’re glowing, making reading uncomfortable. White Point reduces the image’s intensity in software alongside your normal brightness setting, giving the screen a softer appearance.

Adjust the intensity, choose a keyboard shortcut, and schedule it with fixed times, sunrise/sunset, or Night Shift. Optional launch at login.

For Apple Silicon Macs running macOS 13 or later.

## Install

With Apple's command-line tools installed, run `./build.sh`, then move **White Point.app** to your Applications folder and open it. The app appears in the menu bar.
